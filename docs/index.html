PDFForge Studio is a lightweight (~6.4 MB), privacy-first desktop PDF reader and editor built in pure Rust. Enjoy smooth touchpad pinch zoom, highlighter & shapes, live page text/image editing, page organization, print studio, and distraction-free presentation mode — completely offline with zero telemetry.

Capabilities

Everything You Expect in a Modern Desktop PDF Suite

Engineered for speed, accuracy, and complete offline autonomy — without bloated cloud accounts or heavy runtime installers.

🔍

Precision Pinch & Marquee Zoom

Smooth two-finger touchpad pinch zooming, Ctrl+Wheel, drag-box Marquee zoom, Fit Width/Page, and consistent zoom preserved across every page and Full Screen slide.

🖌

Text Selection & Highlighter Tools

Accurate .textLayer selection popup with instant Copy, Highlight, Underline, Strikethrough, plus freehand highlighter brush and translucent shape overlays.

✎

Edit Page Content (Text & Images)

Dedicated Right Bar panel scans active page text runs and images so you can edit text blocks, restyle typography, replace images, place signatures, or redact.

🖥

Presentation Full Screen (Ctrl+L)

Auto-hiding 3-second top hint banner, bottom hover-reveal HUD bar, touchpad swipe & keyboard slide navigation, plus full scroll restoration on exit.

🗂

Responsive Page Organizer

Drag-and-drop thumbnails or swap exact page numbers, rotate CW/CCW, duplicate, delete, or merge pages from other PDFs with cached previews.

🖨

Acrobat-Style Print Studio & Utilities

Enumerates Windows printers with Copies, Grayscale, Save Ink, Poster/Multiple/Booklet layouts, plus Merge, Split, Watermark, Crop, Compress & Encryption.

🔄

In-App Updater & Clean Uninstaller

Built-in Help → Check for Updates... upgrades locally via .exe package or manifest URL, and the Win10/11 manifested uninstaller leaves zero residue.

🔒

Strict Offline Privacy Guarantee

All JS, CSS, cmaps, standard fonts, and workers load locally via pdfforge://localhost/. Recents, settings, and signatures remain in local %APPDATA%.

⚡

Lightweight ~6.4 MB Native Binary

Migrated from Electron (~150+ MB) to native Rust (tao + wry WebView2), eliminating WebView2Loader.dll static import dependency on Windows.
