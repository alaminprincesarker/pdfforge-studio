## 1. Core Architectural & Privacy Requirements

| ID | Requirement | Status | Primary Section(s) |
|---|---|---|---|
| **ARCH-01** | **Pure Rust + Embedded Static UI**: All native windowing, dialogs, persistence, installer logic, and resource embedding are written in Rust (`Cargo.toml`, `build.rs`, `src-rust/*.rs`). No Node/npm build pipeline, `.tsx` sources, or Electron runtime shipped. | Implemented | [Cargo.toml](Cargo.toml), [build.rs](build.rs), [src-rust/main.rs](src-rust/main.rs) |
| **ARCH-02** | **100% Offline & Zero Telemetry**: All assets (`PDF.js` worker, `cmaps/`, `standard_fonts/`, UI JS/CSS) embedded via `rust-embed` and served over custom `pdfforge://localhost/` protocol; zero outbound requests. | Implemented | [src-rust/main.rs](src-rust/main.rs), `src-rust/assets/` |
| **ARCH-03** | **Zero External `WebView2Loader.dll` Static Import**: Custom C shim (`wv2_shim.c`) + `build.rs` extracts embedded `WebView2Loader.dll` into `%APPDATA%\pdfforge` and loads it dynamically so `PDFForge-Rust.exe` starts cleanly anywhere. | Implemented | [build.rs](build.rs), [src-rust/wv2_shim.c](src-rust/wv2_shim.c), [src-rust/main.rs](src-rust/main.rs) |
| **ARCH-04** | **Local AppData Persistence**: Recent files, favorites, per-PDF reading state (`lastPage`, `lastZoom`, `lastRotation`), preferences, autosave cache, and saved signatures stored under `%APPDATA%\pdfforge`. | Implemented | [src-rust/store.rs](src-rust/store.rs) |
